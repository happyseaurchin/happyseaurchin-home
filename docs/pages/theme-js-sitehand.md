# `theme.js` siteHand

the code card, handing a page on in person (17 Nov 2026, lane kernel-tidy.1, thread 49; David: 'a simple qr code I can flash them', then 'add the code to the pages with their own doors too'): one `<dialog>` over the page, opened by any element marked `data-hand-on` (the shared door's 'Someone beside you? Show this page as a code', on every page that carries the door), or by `window.siteHand.open()`. It draws the page's own address (`https://` and the canonical host and path, never a query or hash) as a QR code, dark on white in either theme, the address written beneath it, `/vendor/qrcode.js` fetched on the first use, never before. A page may say what its code carries for the person showing it: `window.siteHandUrl(handle)` returns the address to encode, and `window.siteHandAsk = { label, empty }` names that handle in a box above the code, filled from the name this device signs with (`render:who`), the code redrawn as it is changed. `/mind-meld` does (its code carries `?with=<handle>`, so whoever scans it melds with the person showing it, and a blank box means David). Its keys are its own: Escape closes it back to the button that opened it, and a door beneath never sees them. It writes nothing and keeps nothing. The style goes in at load, so a page's own `data-hand-on` button wears `.sh-btn` before the card first opens.
